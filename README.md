# Ludum-Dare-59
# The Game:
A short horror game where you explore a cave trying to find treasure. You need to use a scanner to navigate but be careful as you aren't the only thing down there.
<img width="1920" height="1080" alt="game" src="https://github.com/user-attachments/assets/3e3be02f-161b-4688-b092-844a1c3b6687" />

V1.1 is the version that was submitted to the Gamejam.
V2.0 is a version with many QOL and bugfixes with some visual changes.

# Play Instructions (Windows):

Unzip TreasuresBelow.zip.  
Run TreasuresBelow.exe

# Controls:

WASD --- Move  
Mouse --- Look  
E --- Interact / Pickup / Drop  
Left Click --- Scan  
Shift --- Run
